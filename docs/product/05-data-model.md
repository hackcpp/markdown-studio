# 05 — 数据模型与存储

## 笔记与应用数据

工作区中的 `.md` 文件保存正文和 Frontmatter。Electron 应用数据目录保存搜索索引和会话数据。

| 位置 | 内容 |
| --- | --- |
| 工作区内的 `.md` | 正文和 YAML 元数据 |
| 工作区内的 `Attachments/images/` | 应用保存的粘贴图片 |
| `search.sqlite` | 可从工作区重建的 FTS5 索引，按工作区区分路径、标题、正文和文件状态戳 |
| `sessions/` | 最近工作区、打开的标签、编辑模式、收藏、最近访问和恢复草稿 |
| `recovery/` | 显式覆盖冲突前备份的磁盘版本 |

主题偏好由渲染进程本地存储保存。重建索引应保留会话数据和原笔记。

## Frontmatter

新建笔记自动写入 `title`、`created`、`modified` 和 `tags`。标题默认取文件名，日期使用 ISO 8601，标签初始为空。成功保存时更新可安全修改的 `modified`，保留 `created`。用户可以通过「文档信息」修改标题和标签。

修改文档信息时按 YAML 节点范围更新目标字段，保留无关字段、排版和正文。无法安全局部修改时提示使用源码编辑。见[文档信息与 Frontmatter](11-feature-follow-up.md#文档信息与-frontmatter)。

## 索引和保存基线

发起搜索时递归核对路径和文件状态戳，更新有变化的索引记录。索引初始化失败时可退回内存索引。手动重建和持久库恢复见[搜索定位与工作区维护](11-feature-follow-up.md#搜索定位与工作区维护)。

保存和冲突检测使用 SHA-256 基线哈希。写入成功后更新基线，磁盘内容与基线不符时进入冲突处理。
