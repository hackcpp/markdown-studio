# 03 — 编辑器与交互规格

## 1. 编辑体验决策

提供两种编辑状态：

1. **实时预览编辑**：用户在 Markdown 编辑体验中编辑，预览同步更新。
2. **源码模式**：直接编辑原始 Markdown 文本。

使用一个图标切换，悬停提示目标状态。编辑与源码共享同一份文档状态，切换时保留内容、光标状态和未保存状态。

## 2. 编辑器能力

编辑器支持语法高亮、自动换行、文档内查找、撤销和重做。实时预览支持标题、段落、列表、引用、代码块、链接、图片、GFM 表格与任务列表、LaTeX 公式和 Mermaid 图表。编辑内容变更触发自动保存。

### 工具栏
- 粗体
- 斜体
- 删除线
- 标题
- 无序列表
- 有序列表
- 引用
- 行内代码
- 链接
- 图片
- 表格
- 撤销和重做

工具栏必须对当前编辑器 selection 生效；不能只在某一种模式中有效却没有提示。若特定操作无法在实时编辑模式可靠实现，应提供一致的命令入口或清晰禁用状态。

## 4. 保存状态机

```text
Saved
  └─ 用户输入 → Dirty
Dirty
  └─ 防抖计时（约 800ms）→ Saving
Saving
  ├─ 写入成功且内容未再变化 → Saved
  ├─ 写入成功但期间内容变化 → Dirty → 再次保存
  └─ 写入失败 → Error
Error
  ├─ 用户重试 → Saving
  └─ 继续编辑 → Dirty
```

重要约束：
- 保存必须按文件串行化，不能让旧内容的慢写入覆盖新内容。
- UI 中的“已保存”只能在文件写入成功后显示。
- 保存失败不得清除 dirty 状态或恢复数据。
- 保存成功后更新磁盘基准，索引在搜索时核对。

## 5. 标签页行为

- 多标签页是已确认需求。
- 每个标签保存独立文档状态。
- 切换标签不应重建/丢失未保存内容。
- 标签有未保存内容、正在保存、存在待恢复草稿或未解决冲突时，拦截关闭并提示用户先处理。用户处理后再次关闭。
- 启动时恢复所有仍可打开的标签及带未处理草稿的标签，优先选中上次活动笔记。
- 上次活动笔记无法恢复时，选中最后一个可恢复标签。没有任何可恢复标签时，显示工作区空状态。
- 退出时若仍有待处理内容，提示返回编辑器或直接退出。直接退出后，草稿以最近一次写入的恢复检查点为准。

## 6. 右侧目录

- 默认收起。
- 根据 Markdown 标题生成目录。
- 支持 H1-H6 层级显示。
- 点击目录项定位到标题。
- 编辑标题后目录应同步更新。
- 标题重名时定位应使用文档位置/节点 ID，不只按标题文本匹配。

## 7. 中文输入法要求

必须测试：
- 拼音输入过程中候选字未确认时，不触发错误的保存/转换行为。
- 输入法 composition 期间不重建编辑器实例。
- 组合输入完成后正常更新预览和保存状态。
- 中英文混排、全角标点、中文括号、emoji。
- 从其他应用粘贴中文内容。

## 8. Markdown 解析与安全
- 使用成熟 Markdown parser，不自行用正则实现完整 Markdown 解析。
- 原始 Markdown 为存储内容。
- HTML 预览必须经过 sanitization。
- 不执行笔记中的脚本或任意 HTML 事件。
- 外部链接打开前应限制协议，拒绝 `javascript:` 等危险协议。
