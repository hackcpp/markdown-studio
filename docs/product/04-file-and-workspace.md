# 04 — Workspace 与文件管理规格

## 1. Workspace 定义

Workspace 是用户选择的普通本地文件夹。应用不接管或私有化该目录。

建议示例：
```text
MyNotes/
├── Inbox/
├── Learning/
│   ├── AI/
│   └── Photography/
├── Projects/
├── Writing/
└── Attachments/
    └── images/
```

上面是示例结构，不强制用户必须采用固定目录。

## 2. 文件扫描
- 递归扫描 Workspace。
- 识别 `.md`（扩展名大小写不敏感）。
- 文件夹可展开/折叠。
- 扫描跳过以点开头的条目以及符号链接。搜索时按文件树核对索引。
- 不扫描 Workspace 外部路径作为笔记正文。

## 3. 新建笔记
- 选中文件夹时默认使用该文件夹。选中笔记时默认使用笔记所在文件夹。选中工作区顶层时默认使用工作区顶层。
- 可在新建对话框中改选已有目录。Inbox 是普通目录，由用户按需创建。
- 文件名自动补 `.md`。
- 同目录同名冲突必须提示，不自动覆盖。
- Frontmatter 基础字段由应用创建。

## 4. 文件操作

| 操作 | 规则 |
|---|---|
| 新建文件夹 | 在当前目录创建 |
| 重命名笔记 | 重命名实际 `.md` 文件并更新索引、标签页路径 |
| 移动笔记 | 移动实际文件；更新索引与打开标签路径 |
| 删除笔记 | 经确认移入系统回收站或废纸篓 |
| 删除文件夹 | 经确认整体移入系统回收站或废纸篓。影响范围提示见[删除文件夹确认](11-feature-follow-up.md#删除文件夹确认) |
| 外部修改 | 检测并进入冲突保护流程 |

移动或重命名成功后更新标签页和文件树。下次搜索时核对索引。移动失败时应保留文件，并明确提示无法回滚的情况。

## 5. 附件
应用将粘贴的图片保存到工作区内的 `Attachments/images/`，并插入相对路径。
- 粘贴图片时生成唯一文件名，避免覆盖。
- 插入 Markdown 图片语法：`![alt](../Attachments/images/name.png)`（相对路径应按实际笔记目录计算）。
- 应用内移动时更新受影响的 Markdown 链接与本地图片引用。侧栏标出 `Attachments` 目录。外部移动的重新关联规则见[移动笔记与附件引用](11-feature-follow-up.md#移动笔记与附件引用)。
- 删除笔记不能自动删除可能被其他笔记引用的附件。
- 孤立附件检查见[搜索定位与工作区维护](11-feature-follow-up.md#搜索定位与工作区维护)。

## 6. 外部文件变化
文件监听至少覆盖：
- 新建、删除、重命名、移动。
- 内容修改。
- 原子替换导致的 rename/change 事件。
- 批量操作和短时间重复事件去抖。

文件监听事件不能直接触发覆盖。对于当前正在编辑的文件，必须比较磁盘版本、编辑器版本和上次已保存基线。

## 7. 路径安全
- Renderer 不传任意绝对路径给主进程。
- IPC 接口使用 Workspace 相对路径。
- 主进程解析并校验路径必须位于 Workspace 内。
- 防止 `../` 路径穿越。
- 支持 Unicode 文件名。文件访问拒绝经过的符号链接。
