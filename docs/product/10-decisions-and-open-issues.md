# 10 — 产品决策

## 已确认的行为

| 项目 | 决策 |
| --- | --- |
| 产品定位 | 简洁、可靠的本地 Markdown 桌面笔记，优先编辑、管理和搜索 |
| 存储 | Markdown 文件保存正文和元数据，SQLite 索引可重建 |
| 启动恢复 | 恢复所有仍可打开的标签和带未处理草稿的标签。优先选中上次活动笔记，失效时回退到最后一个可恢复标签 |
| 新建位置与 Inbox | 默认使用选中文件夹、选中笔记所在文件夹或工作区顶层。已有 Inbox 可在新建对话框中选择 |
| 关闭标签 | 标签有未保存内容、正在保存、草稿待恢复或冲突未解决时拦截关闭。提示用户处理后再关闭 |
| 编辑模式 | 实时预览与源码，由一个图标切换 |
| 导航 | 搜索入口在左侧栏，右侧文档目录默认收起，文件操作放在上下文菜单 |
| Frontmatter | 自动维护基础字段，标题和标签可编辑 |
| 删除 | 文件移入系统回收站或废纸篓 |
| 恢复 | 支持未保存草稿与冲突保护。历史版本时间线暂不纳入 |

[待实现功能规格](11-feature-follow-up.md)记录草稿与冲突、文件操作、Frontmatter、编辑快捷键以及搜索维护的交互和验收目标。
