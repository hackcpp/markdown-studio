# 01 — 产品需求

Markdown Studio 是面向个人知识积累的本地 Markdown 桌面笔记应用，提供 Windows 和 macOS 版本。用户在自选文件夹里编辑、整理、搜索笔记，也能用其他工具打开同一批文件。

## 功能范围

| 场景 | 当前能力 |
| --- | --- |
| 开始使用 | 选择工作区并递归浏览文件树。应用记住上次工作区和标签 |
| 写作 | 多标签编辑，实时预览与源码一键切换，格式工具栏、文档目录和浅色／深色主题 |
| 整理 | 创建、移动、重命名及移入系统回收站或废纸篓。支持收藏、最近打开、图片粘贴与基础元数据 |
| 搜索 | 按标题、正文和相对路径搜索，支持中文短词 |
| 保护编辑 | 自动保存、保存状态、草稿恢复和外部文件变动提示 |

当前范围排除云同步、多端协作、历史版本时间线、AI、双链图谱、插件生态及项目管理看板。
