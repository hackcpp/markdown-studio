# 02 — 信息架构与界面规格

## 1. 主窗口结构

采用现代桌面工作空间风格，主窗口分为：

1. 顶部应用栏。
2. 左侧导航与文件树。
3. 中央标签页与编辑工作区。
4. 可选右侧文档目录。
5. 底部状态栏。

## 2. 区域规格

### 2.1 顶部应用栏
- 应用标识与名称。
- 当前 Workspace 名称。
- 新建笔记入口。
- 设置入口。
- 主题切换图标。

### 2.2 左侧栏
导航项：
- 搜索，支持全局快捷键。
- 最近。
- 收藏。
- 工作区文件树，根节点显示当前工作区名称。

文件树要求：
- 支持多层级文件夹。
- 文件夹可展开/折叠。
- Markdown 文件作为叶子节点。
- 当前打开/选中笔记有明确视觉状态。
- 重命名、移动和移入回收站或废纸篓通过条目的右键菜单提供。
- 附件目录的归类见[移动笔记与附件引用](11-feature-follow-up.md#移动笔记与附件引用)。

### 2.3 标签页
- 支持同时打开多篇笔记。
- 标签显示文件名或 Frontmatter title。
- 当前标签有明确高亮。
- 未保存状态使用小圆点等轻量提示。
- 有未保存内容、保存正在进行、草稿待恢复或冲突未解决时，关闭操作保持标签打开并提示处理。
- 启动恢复上次仍可打开的标签及有待恢复草稿的标签。优先选中上次活动笔记，其无法恢复时选中最后一个可恢复标签。

### 2.4 中央编辑区
- 编辑区使用一个图标在实时预览与源码之间切换。
- 同一文档状态驱动两种模式。
- 编辑器区域宽敞，避免过多面板。
- 工具栏只放常用格式操作。

### 2.5 右侧目录
- 默认收起。
- 用户主动打开后显示当前文档标题层级。
- 点击标题滚动到对应位置。

### 2.6 底部状态栏
- 保存状态包括已保存、未保存、保存中和保存失败。
- 字数和字符数。
- 文档格式（Markdown）。
- 编码（UTF-8）。
- 手动保存入口。

## 3. 主要页面/状态

| 页面/状态 | 说明 |
|---|---|
| 欢迎页 | 尚未选择 Workspace |
| 工作区空状态 | Workspace 已选但没有 Markdown 笔记 |
| 工作区主界面 | 文件树、标签页、编辑器 |
| 搜索面板 | 输入与结果列表 |
| 新建笔记对话框 | 名称与保存位置 |
| 删除确认 | 说明将移入系统废纸篓 |
| 冲突处理 | 展示磁盘版本与编辑器版本的选择 |
| 异常恢复 | 当前在标签页提示恢复。独立草稿清单见[草稿与冲突](11-feature-follow-up.md#草稿与冲突) |
| 设置 | Workspace、编辑器偏好、主题等 |

## 4. 视觉原则

- 现代、简洁、低饱和。
- 浅色主题作为默认基线；深色主题作为配套。
- 使用清晰层级，不使用大量卡片和装饰。
- 重点突出文档内容而不是应用 chrome。
- 面板分隔线轻量，状态颜色只用于必要反馈。
- 交互控件保持桌面应用的密度与可点击面积。

## 5. 响应式与窗口行为
桌面窗口支持缩放：
- 窄窗口时右侧目录可隐藏。
- 左侧栏可折叠。
- 编辑区优先保留宽度。
- 不允许缩放导致标签页或编辑器不可操作。
