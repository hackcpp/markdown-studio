# 07 — 搜索

## 搜索流程

左侧「搜索」和 `Ctrl+Shift+F`（macOS 为 `⌘⇧F`）打开搜索面板。查询覆盖标题、正文和相对路径。结果显示标题、路径和摘要，点击后打开或切换到目标标签。无结果时显示空状态。目标笔记内的命中定位见[搜索定位与工作区维护](11-feature-follow-up.md#搜索定位与工作区维护)。

## 中文搜索与索引

当前用 SQLite FTS5 trigram 查询三个及以上字符，一、二字符使用 LIKE。搜索正文排除 Frontmatter，标题和路径单独检索。索引文件和更新时机见[数据模型](05-data-model.md#索引和保存基线)。

## 搜索验收样例

- 中文短词 `发布`、`上下文` 和连续中文 `注意力机制`。
- 英文 `Transformer`、中英文混排 `Attention 机制`。
- 中文文件名、重复命中、标点和通配符字面量。
- 移动、重命名或外部删除后的结果路径。
