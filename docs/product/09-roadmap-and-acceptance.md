# 09 — 发布验收

## 发布产物

[Release 工作流](../../.github/workflows/build.yml)在 Release 发布后打包并上传 Windows x64、macOS Apple Silicon 和 macOS Intel 安装包。实际下载以[最新发布页](https://github.com/hackcpp/markdown-studio/releases/latest)为准。macOS Developer ID 签名、公证和实机安装升级验收仍待完成。

## 回归检查

| 场景 | 验收条件 |
| --- | --- |
| 启动与标签 | 恢复仍可打开的标签、待恢复草稿和上次活动笔记。待处理内容按[关闭规则](03-editor-interaction.md#5-标签页行为)保护 |
| 文件操作 | 新建目录符合[默认位置规则](04-file-and-workspace.md#3-新建笔记)。同名操作不覆盖。移动后标签和搜索结果指向新路径，删除进入系统回收站或废纸篓 |
| 编辑 | 预览和源码切换保留内容与光标。撤销、重做、常用 Markdown 渲染及中文输入法正常 |
| 搜索 | 中文、英文和混排可检索，结果打开正确笔记。样例见[搜索规格](07-search-spec.md#搜索验收样例) |
| 保存与恢复 | 保存失败时保留编辑内容及原文件。外部修改提示冲突，异常退出可从最近检查点恢复 |
| 安装与升级 | Windows 与 macOS 实机验证安装、首次工作区授权、升级、卸载及笔记数据保留 |

文件测试覆盖中文路径、`.md` / `.MD`、空文件、超长文件和大量小文件。可靠性验收覆盖只读权限、磁盘空间不足、外部移动、强制退出和睡眠唤醒。界面验收覆盖深浅主题、高 DPI 和窄窗口。

[待实现功能规格](11-feature-follow-up.md)列出各功能的验收条件，按功能逐项检查。
