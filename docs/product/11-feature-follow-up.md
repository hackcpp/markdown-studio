# 11 — 待实现功能规格

下列功能按本文顺序逐项实现和验收。启动恢复、创建位置和关闭标签的现行规则见[产品决策](10-decisions-and-open-issues.md)。

## 草稿与冲突

- 在当前工作区提供「恢复草稿」入口。列表显示笔记名、相对路径、最近检查点时间和磁盘状态。支持预览、恢复到编辑器、明确放弃单条草稿。
- 检查点保存草稿及基线正文和哈希。比较区可查看基线、草稿和当前磁盘版本，并突出发生变化的行。仅带基线哈希的历史草稿继续可恢复，界面说明基线正文不可用。
- 恢复前重读磁盘。磁盘已变化或文件不存在时进入冲突处理，保留草稿。用户可保留草稿并继续编辑、采用磁盘版本，或显式保存草稿。覆盖前备份磁盘版并再次核对磁盘哈希。
- 会话恢复与待处理清单共享同一条草稿记录。成功保存或明确放弃后移除记录。

**验收**　同一工作区有多条草稿时可独立处理。覆盖前再次外部修改会阻止覆盖。丢失文件和旧格式草稿仍可进入清单。

## 移动笔记与附件引用

- 应用内移动笔记、目录或重命名时，计算受影响的工作区内相对 Markdown 链接与本地图片引用。包含随文件迁移的链接，以及其他笔记指向移动目标的链接。
- 通过 Markdown 解析定位链接目标，仅修改路径部分。保留链接文字、图片说明、引用定义、查询参数和锚点。兼容中文、空格和多层 `../`。代码和外部链接保持原文。
- 保存受影响的文件前核对磁盘基线。存在未保存编辑、同名目标或外部写入时，提示相关路径并暂停操作。文件操作完成后，同步标签、收藏、最近和索引状态。
- 对外部移动，只有可以可靠匹配源和目标时才给出重新关联入口。无法确认时保留原标签和草稿，提示原路径失效，由用户重新选择目标。
- 在笔记树中将附件目录与普通笔记区分。检查功能报告失效引用和疑似孤立附件，附件仍可通过文件系统访问。

**验收**　测试跨目录移动及文件夹重命名、中文与空格路径、手写图片链接和指向移入文件的反向链接。移动被阻止时，磁盘文件、草稿和已有链接保持可恢复。

## 删除文件夹确认

- 点击「移至废纸篓」后，展示相对路径、子目录数和文件数。非空目录明确说明会将整个目录及所有子项一并移走，计数包含侧栏未展示的文件。
- 受影响的打开标签若有未保存内容、待恢复草稿或未解决冲突，列出这些笔记并拦截操作。确认时若目录范围已变化，刷新统计后再次确认。
- 成功后同步文件树、打开标签、最近和收藏。失败时保留当前界面状态并显示错误。

**验收**　空目录、普通非空目录、含隐藏文件的目录、含未保存草稿的目录均给出正确提示。取消操作不写入任何文件。

## 文档信息与 Frontmatter

- 在「文档信息」编辑标题和标签时，依据 YAML 节点范围修改目标字段。保留其余字段的文本、顺序、注释、缩进、引号、分隔符、换行格式和正文。
- `created` 保持原值，成功保存时只对可安全更新的 `modified` 做局部替换。缺少可编辑字段时可在合适位置添加。
- YAML 无法解析、目标字段重复或形式复杂到无法局部修改时，说明原因并引导用户在源码模式编辑。旧笔记无 Frontmatter 时，显式编辑文档信息才创建基础字段。

**验收**　分别测试带注释的 YAML、未知字段、多行值、CRLF、缺失字段和无效 YAML。对比保存前后，只有本次编辑字段与应维护的 `modified` 发生变化。

## 编辑快捷键与缩进

- Windows 使用 `Ctrl`，macOS 使用 `⌘`。实现 `B` 粗体、`I` 斜体、`N` 新建笔记、`W` 关闭当前标签。关闭快捷键调用现有的关闭保护逻辑。
- 粗体和斜体只在编辑器内生效，使用与工具栏一致的选区操作。搜索框、对话框和输入法组合期间，编辑命令不可误触发。
- 列表内使用缩进命令调整层级。普通编辑器允许 Tab / Shift+Tab 移动焦点，并为缩进和取消缩进提供显式键位及可访问的说明。保留撤销、重做、查找和保存快捷键。

**验收**　预览和源码模式的选区结果一致。键盘用户可离开编辑器。测试列表与多行选区、编辑撤销、中文 IME 和关闭有草稿的标签。

## 搜索定位与工作区维护

- 搜索结果展示命中字段和摘要。点击正文命中项时打开或切换标签，滚动到匹配行并高亮该处。仅命中标题或路径时打开文档顶部。内容变化后重新定位，已有草稿优先参与定位。
- 在设置中提供「重建搜索索引」。显示进度和结果，构建成功后再替换可用的旧索引。损坏索引先保留用于排查，重建失败时说明原因并允许重试。整个过程只写应用数据目录。
- 提供只读「工作区检查」，报告无法读取、索引异常、Frontmatter 解析异常、失效的本地图片或笔记链接、疑似孤立附件和待处理草稿。报告项可打开对应笔记或进入对应处理入口。

**验收**　用中文短词、中英文混排、同词重复和标题命中验证定位。测试重建失败时的重试、坏库恢复及检查过程中继续编辑。工作区检查原始文件内容保持一致，收藏、最近和草稿不随索引重建清除。
